It's been some time since I last wrote a blog post, I never really think of writing what I am doing at the moment and then I feel bad because I never write about anything, chicken egg situation. I'm trying to improve my life and writing here should make progress so here we go.

Three or four months ago I was let go by a company that I did some freelancing for in my free time, the work was shit and too much for what they paid me, but it was a complementary thing so I could save some money. Why am I telling you this? Because I got a "severance" (not really, more like a fuck you we are firing you bonus) of which I took $100 and finally did the steamworks partner thingy so I could try and publish my game.

First of all, the process was ok, I fucking hate the whole bureaucracy thing but it was mostly filling forms and waiting around, about two weeks or so I had my account and I could start with the art and steam page of the game so steam could approve or ask for changes.

Then I panicked, at this point the game was more than a PoC but we didn't really have anything to make it really a game, so I slapped a main menu, an icon that I baked in gimp using the game assets that I already made using aseprite and got my MIDI keyboard to do some simple melodies for the game and some sound effects. Some screenshots later I had a steam store page done and a build of the game for steam to review.

2 weeks later I had to change some art and then one more week and I had the game ready for release, I put the game free on steam and it launched on 13th Aug. 

Almost nobody really played but I got some feedback especially from my friends and I unfortunately had to use LLMs not for the game but to setup an automatic deploy to steam pipeline, I want to keep the game LLM free as much as I can, right now I'm just using LLMs to fill issues and help me debugging THEY ARE CRACKED FOR DEBUGGING if you never tried I recommend that you do. 

I just feel so motivated to keep working on it, adding features, achievements, finding and fixing the bugs, and getting more feedback from my friends, It was great! 

Anyway, that's it, I don't have much to say, the game is on steam, play it if you want 

https://store.steampowered.com/app/4980570/Buzzness_Tycoon/
